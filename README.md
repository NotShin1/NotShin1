### 👨‍💻 About My Journey

I am a third-year Information Security student transitioning from a traditional offensive security (Pentest) mindset to a **DevSecOps** approach. 

My current philosophy is simple: **"Security should be built-in, not bolted-on."** I focus on automating security checks within CI/CD pipelines, provisioning infrastructure through code, and implementing robust observability for modern Web2 architectures.

- 🌱 **Currently deep-diving into:** Infrastructure as Code (IaC), Continuous Integration/Continuous Deployment (CI/CD), and integrating security scanning tools directly into the development workflow.
- 🔭 **Short-term goal:** Mastering AWS cloud services and Jenkins for enterprise-grade automation.
